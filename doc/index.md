# 🎓 Unity ゲーム開発（後期）シラバス

3D ゲーム制作を題材に、**課題を分解し、道具を選び、詰まりを抜ける力**を身につけます。
Unity の機能は「題材」です。毎週、技術と一緒に**考え方**を1つ持ち帰ってもらいます。

- 前期（2D 中心）：[Unity Game Dev Tutorial](https://app.notion.com/p/unity-game-dev-tutorial-32f9854442bc8008861cdee72b6597ec)
- 使用バージョン：Unity 6000.3.19f1 / URP 17.3

---

## 🎯 後期の進め方

### 題材は1本。完成形のお手本を毎回参照します

**3Dアクションアドベンチャー『LUMEN』**（セルルック調・塔の探索）を題材にします。
この作品は**すでに完成しています。** 毎回の導入で「作るとこうなる」を見てから、演習に入ります。

ゴールの見えない作業はつらいだけです。**先に完成形を見せます。**

### ただし、1週だけ受けても成立します

- 各週に**専用シーン**と**専用フォルダ**があります
- 各週フォルダには `_Start`（作業前の状態）と `_Goal`（完成見本）が入っています
- 欠席しても `_Start` から入れば、その週の内容に合流できます

積み上げは**課題**の側で行います。だから、続けて受けると自分の作品が育ちます。

### 毎週、課題があります

毎週 3〜5 問、難易度を3段階に分けて出します。

| 難易度 | 内容 |
|---|---|
| **(必須)** | 授業内容を、条件を少し変えて自力で再現する |
| **(推奨)** | 授業で触れた機能を、別の文脈に応用する |
| **(応用)** | 正解が1つに決まらない、設計の余地がある課題 |

提出は **Slack** へ。動作がわかる動画を投稿してください。

さらに後期からは、**振り返り**を毎回必須とします。

> **どこで詰まったか / どう調べたか / どう解決したか** を 3〜5 行で書いてもらいます。
> 「できました」だけの投稿は不可です。

**評価の重心は、この振り返りに置きます。** 動いたかどうかは足切りです。
詰まりを言語化できる人は、授業で扱っていない機能にも自力で到達できるようになります。

## 🎬 お手本作品『LUMEN』

授業では、**完成済みのお手本作品**を毎回参照します。
セルルック調の3Dアクションアドベンチャーで、塔を探索して3つの灯を灯し、最奥のボスを倒すとクリアです。

| | |
|---|---|
| **場所** | `Assets/_DemoGame/` |
| **使い方** | 各回の導入で「作るとこうなる」を見る。**参考展示なので、授業中に編集はしません** |
| **演習** | お手本を見たあと、各週の専用シーン（`Assets/Application/WeekXX-*/`）で自分の手を動かします |

各回で学ぶ技術が、お手本のどこに使われているかは次のとおりです。

| 回 | お手本の中で見るところ |
|---|---|
| Week 01 | 攻撃モーションと、剣が当たる瞬間の判定／箱を押す手の動き（IK） |
| Week 02 | プレイヤー追従カメラ、ボス戦での画角 |
| Week 03 | タイトル後の導入・ギミック解除時・ボス戦前のカットシーン |
| Week 04 | 雑魚敵の追跡、ボスのフェーズ切り替え |
| Week 05 | 灯を点ける前と後での、塔の明るさと色の変化 |
| Week 06 | セルルック調の陰影 |
| Week 07 | 灯が点る瞬間のエフェクト |
| Week 08 | なぜセルルックで作っているのか（PBR との対比）／画面全体にかかった PostProcess |
| Week 09 | 目覚めの間から中央広間への導線、木箱や印の配置 |
| Week 10 | 灯の点灯が HUD・扉・BGM に伝わる流れ |
| Week 11 | タイトル → インゲーム → リザルトの導線 |
| Week 12 | お手本にあえて入れていない機能を探す |
