## 1. 共通のルール

---

| ルール | 内容 |
| --- | --- |
| **マテリアルを増やさない** | `M_FX_Additive`（加算）・`M_FX_AlphaBlend`（アルファ）を基本に、テクスチャが違うときだけ子マテリアル（Material Variant）を作る |
| **個体差は頂点で渡す** | 色・フェードは Start Color / Color over Lifetime、消える量・発光の強さは Custom Data（Custom1.xy）。マテリアルを実行時に変えない（SRP Batcher のため） |
| **ソフトパーティクル** | 地面に触れる物（煙・霧・衝撃波）は `_SoftParticleDistance` を 0.3〜1.0 |
| **光る物は HDR** | 炎・光の柱は色を 1 を超える値にして、Bloom で光らせる |
| **ライトはエフェクトに持たせる** | 炎などに付く Point Light は、エフェクトの Prefab の中に置く（ライトの種類は [11-lighting.md](11-lighting.md) §4） |
| **使い回す物は Pool** | 当たり・着弾など何度も出る物は、Object Pool（`UnityEngine.Pool`）から出す |
| **置き場所** | Prefab は `Graphics/Effects/`、テクスチャは `Graphics/Textures/FX/` |

### 2.1 火（杖・篝火・火焔玉）

---

| # | エフェクト | いつ | 種類 | 優先 | 作り方 |
| --- | --- | --- | --- | --- | --- |
| 1 | **篝火の炎** | いつも | ループ | ◎ | 炎（Texture Sheet の連番 or ノイズを上へ流す板）＋ 火の粉（小さい点・上へ・Noise で揺らす）＋ 薄い煙（AlphaBlend）。Point Light の強さを揺らす |
| 2 | **杖の火** | 杖が灯っている間 | ループ | ◎ | #1 を小さくした物。杖の先に付ける。**火の量（Flame）で大きさ・数を、光の段（Glow）で明るさと色（橙 → 黄 → 白）を変える**（Emission の Rate と Start Size・Start Color をスクリプトから）。動くと火の粉が尾を引く（Simulation Space = World） |
| 3 | **杖に火が移る** | 篝火に杖を近づけたとき | 1回 | ◎ | 篝火から杖の先へ、火の粉が吸い込まれる（Velocity over Lifetime の Orbital / 目標へ寄せる）＋ 杖の先で小さく弾ける |
| 4 | **火焔玉（弾）** | 撃ったとき | 弾 | ◎ | 芯（加算の球の板・明るい）＋ 外側の炎（ノイズで揺らす）＋ 軌跡（Trails）＋ 火の粉。**段で大きさを変える**（チャージなし 1 ／ 1段 1.3 ／ 2段 1.6 ／ 3段 2.4 倍） |
| 5 | **チャージ** | 押している間 | ループ | ◎ | 杖の先に火の粉が集まる（外から内へ）。**段が上がった瞬間にリングが弾ける**（加算の輪・一瞬で広がる）。画面の縁の炎は [11-lighting.md](11-lighting.md) §5.3 |
| 6 | **火焔玉の着弾** | 当たったとき | 1回 | ◎ | 爆発（加算の球が広がって消える）＋ 火の粉が飛び散る（重力あり・地面で跳ねる Collision）＋ 煙。3段は大きく、地面に焦げ跡（地面に寝かせた板・数秒で消える） |
| 7 | **殴りの当たり** | 殴りが当たったとき | 1回 | ○ | 白い小さな火花（Stretched Billboard）＋ 衝撃の輪。**火焔玉より地味にする**（強さの違いを見た目でも出す） |

## 3. 要るテクスチャ

---

| テクスチャ | 使う所 | 用意の仕方 |
| --- | --- | --- |
| `T_Noise`（済） | 消滅・炎の揺らぎ・光の柱 | 実装済み |
| 炎の連番（4×4 程度） | #1・#2・#4・#10・#15 | 無料素材を探す。無ければノイズを流す板で代用 |
| 煙（ふわっとした丸） | #1・#6・#14・#22 | 無料素材 or 自作（ぼかした円） |
| 火の粉・光の粒（丸い点） | ほぼ全部 | 自作（中心が明るい丸） |
| 輪（リング） | #5・#7・#14 | 自作（ぼかした輪） |
| ひび・焦げ跡 | #6・#14 | 無料素材 |
| 円柱メッシュ（上下の縁が薄い UV） | #9・#21 | ProBuilder か Unity の Cylinder |

- **素材を Asset Store から入れたら、[setup.md](../setup.md) の一覧に足す**（外部依存）。自作した物は `Graphics/Textures/FX/` に置き、`.unitypackage` に入れる
- 形はできるだけ**セルルックに合わせて、縁をくっきり**させる（ぼかしすぎない）。炎は段をつけた色（白 → 黄 → 橙 → 赤）

## 4. シェーダーに足すかもしれないもの

---

今のエフェクト経路（ベースの色 × 頂点カラー、消滅、UV を流す、ソフトパーティクル）で、まず全部作ってみます。足りないときだけ、次を検討します（**キーワードは増やさず、プロパティで足す**。[05-graphics.md](05-graphics.md) §6.1）。

| 足すもの | 要るエフェクト | 内容 |
| --- | --- | --- |
| 極座標の UV | #5 のリング・#14 の衝撃波 | 板の UV を極座標にして、輪を外へ流す（[02-spec.md](02-spec.md) §1.2 にある手法） |
| 縁を光らせる（フレネル） | #16・#26 の殻 | 縁ほど明るく、正面は透ける |
| 近いほど薄くする | #22 の霧 | カメラの近くの板を消す |

## 7. 実装状況（2026-10-02）

### 7.1 作り方

---

| 項目 | 内容 |
| --- | --- |
| テクスチャ | `Graphics/Textures/FX/`：`T_FX_Dot`（丸）・`T_FX_Flame`（炎の涙形。内側と外側の2段）・`T_FX_Smoke`（煙）・`T_FX_Ring`（輪）。**自作**（外部素材なし） |
| マテリアル | `M_FX_FlameAdd`・`M_FX_DotAdd`・`M_FX_RingAdd`（ソフトパーティクルなし）＝ `M_FX_Additive` の子 ／ `M_FX_SmokeAlpha`・`M_FX_FogAlpha`（ソフトパーティクル 1.5）＝ `M_FX_AlphaBlend` の子 |
| Prefab | `Graphics/Effects/FX_*.prefab`。**ルートは空で、子にパーティクルを持つ**。1回だけのものはルートに `FxAutoDestroy` |
| 出し方 | 1回だけ：`FxSpawner.Spawn(prefab, 位置)` ／ ループ：`FxSpawner.Attach(prefab, 親)`（親の拡縮を打ち消して付ける）。**部品は Prefab を参照するだけ**で、Prefab の中に入れ子にしていない（見た目を差し替えても参照が切れない） |
| 色 | エフェクト経路は頂点の Custom Data を受けるが、既定の頂点ストリームでは発光の強さ（`TEXCOORD0.w`）が 1 になり、**色が 2 倍で出る**。色は 1 以下で書き、Bloom で光らせている |
